# Site SUP IMOFOS

## Lancer le site dans VS Code

1. Ouvrez ce dossier dans VS Code.
2. Installez l'extension **Live Server** si elle n'est pas déjà présente.
3. Faites un clic droit sur `index.html`, puis choisissez **Open with Live Server**.

Le site s'ouvrira dans votre navigateur. Vous pouvez modifier :

- `index.html` pour les textes, rubriques et filières ;
- `style.css` pour les couleurs et la mise en page ;
- `script.js` pour les interactions ;
- `logo-sup-imofos.png` pour le logo.

Les images d'illustration sont chargées depuis Unsplash. Pour un déploiement totalement autonome, remplacez-les par vos propres images placées dans le dossier, puis modifiez leurs attributs `src` dans `index.html`.
